Module async_api 

Source
Expand description

Native async API, modeled on Turso’s Rust binding.

use velocidb::async_api::Builder;

let db = Builder::new_local("app.db").build().await?;
let conn = db.connect()?;

conn.execute("CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT)").await?;
conn.execute("INSERT INTO users VALUES (1, 'Alice')").await?;

let rows = conn.query("SELECT * FROM users").await?;
println!("{} row(s)", rows.rows.len());

The engine itself is synchronous; this layer offloads every call onto the tokio blocking thread pool so async tasks never stall the reactor. Because readers run concurrently in the engine, multiple in-flight query futures execute in parallel across blocking threads.
